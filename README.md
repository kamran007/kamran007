## 👋 About me

I build immersive web experiences where interaction design matters as much as the code underneath. My focus is **React**, **Next.js** and **real-time 3D with Three.js**: interfaces that stay fast while doing things people rarely expect from a browser.

- 🏢 **Senior Programmer** at [Codixel](https://codixel.tech)
- 📍 Dhaka, Bangladesh
- 🧊 Most of my time goes into interactive 3D on the web: loading and optimising models, lighting and materials, and keeping scenes at 60fps
- 🛍️ Custom Shopify themes in Liquid (Online Store 2.0)
- 🟢 **Open to freelance and full-time roles**
